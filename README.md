# Mapacha Food Court — Independent Redesign Demo

A responsive front-end concept made with plain HTML, CSS and JavaScript. It is not an official Mapacha Food Court website and is not affiliated with the business.

## Files
- `index.html` — page content and sections
- `style.css` — responsive visual design
- `script.js` — mobile navigation and demo interaction messages

## Run locally
1. Extract the ZIP file.
2. Open the folder in VS Code.
3. Open `index.html` in your browser, or use the Live Server extension.

## Before presenting or launching
- Confirm the business name, branding and permission to use its identity.
- Replace illustrative category cards with verified kiosk names and official menu links.
- Confirm all menu items, prices, opening hours, contact details and ordering destinations with the business.
- Review image licenses and replace imagery as needed for commercial use.
- This demo uses Google Fonts and externally hosted Unsplash images, so an internet connection is needed to load them.
